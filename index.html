A lightweight, readable JavaScript utility library.

🔹 Core

get("id")

Gets an element by ID

---

📦 Elements

hide("id")

Hides element

show("id")

Shows element

toggle("id")

Switches visibility

remove("id")

Deletes element from page

clear("id")

Clears inner content

---

🖱️ Events

click("id", fn)

Runs function on click

dbl("id", fn)

Runs function on double click

hover("id", on, off)

Hover in/out events

input("id", fn)

Runs on typing/input

key(fn)

Keyboard press event

---

🎨 Style

css("id", {color:"red"})

Change styles

add("id","class")

Add class

rem("id","class")

Remove class

tog("id","class")

Toggle class

---

📝 Text

text("id","hello")

Set text

html("id","<b>hi</b>")

Set HTML

addText("id","more")

Adds text

---

📊 Input

val("id")

Get input value

setVal("id","value")

Set input value

clearVal("id")

Clear input

Play media

stop("id")

Stop and reset media
